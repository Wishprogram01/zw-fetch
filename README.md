# zw-fetch

A custom, blazingly fast system fetcher and terminal quick-note dashboard built in Rust for Ubuntu/WSL environments.

## Features
- **Custom Dual-Color Ubuntu ASCII Art**: Accurate ANSI-colored logo.
- **Bloody Style Title Banner**: Custom Unicode block art header.
- **System Info**: Real-time OS, RAM usage, and host details.
- **Built-in Terminal To-Do / Quick Notes**: Add and view daily developer tasks directly upon opening the terminal.

## Usage
```bash
# Run fetcher
zw-fetch

# Add a quick note / task
zw-fetch add "Push code to GitHub"

# Clear all tasks
zw-fetch clear
